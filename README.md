# MKXA OS

**MKXA OS** – własny system Linux tworzony na bazie **Fedory**, z naciskiem na szybkość, prostotę i zastosowania gamingowe.

> 🚧 **Status: aktywny rozwój / wersja eksperymentalna**

## 🎯 Cel projektu

MKXA OS jest projektem edukacyjnym i eksperymentalnym. Celem jest stworzenie własnej dystrybucji Linuxa z własnym wyglądem, konfiguracją i narzędziami, zamiast zwykłego instalowania gotowego systemu.

Projekt jest rozwijany stopniowo i jego konfiguracja może się zmieniać.

## 🧱 Baza systemu

- **Fedora Linux**
- Architektura docelowa: **x86_64**
- Środowisko graficzne: **KDE Plasma** *(w trakcie tworzenia)*
- Własna konfiguracja **Fastfetch**
- Własna identyfikacja wizualna MKXA OS
- Instalator **Calamares** *(planowany / w trakcie konfiguracji)*

## 🚀 Planowane elementy

- własne logo MKXA OS
- własna konfiguracja Fastfetch
- dopracowany wygląd KDE Plasma
- automatyczne logowanie w trybie Live, jeśli będzie potrzebne
- instalacja systemu przez Calamares
- optymalizacje pod szybkość i gry
- własne skrypty i konfiguracja systemu
- gotowy obraz ISO do uruchomienia z USB

## 🧪 Stan projektu

MKXA OS **nie jest jeszcze gotowym systemem do codziennego użytkowania**.

Obecnie projekt jest rozwijany i testowany. Poszczególne elementy mogą być niekompletne, zmieniać się albo nie działać prawidłowo.

Nie należy traktować obecnych wersji jako stabilnego wydania.

## ⚠️ WAŻNE – ZANIM URUCHOMISZ LUB ZAINSTALUJESZ

MKXA OS jest tworzony w celach edukacyjnych i eksperymentalnych. System może zawierać błędy lub nieprzewidziane zachowania.

**Używasz systemu na własną odpowiedzialność.**

Autor nie ponosi odpowiedzialności za:
- utratę danych,
- uszkodzenie sprzętu,
- problemy ze zgodnością,
- błędy systemu,
- problemy wynikające z instalacji lub użytkowania na nietypowym sprzęcie.

Przed instalacją wykonaj kopię zapasową ważnych danych.

**Nie instaluj wersji testowej na komputerze zawierającym jedyną kopię ważnych plików.**

## 💻 Kompatybilność

Głównym celem projektu jest sprzęt **x86_64**. Kompatybilność z konkretnymi komputerami i podzespołami może się różnić.

Sterowniki, firmware oraz obsługa konkretnego sprzętu zależą również od bazy Fedory i konfiguracji MKXA OS.

## 📦 Wydania

Na tym etapie projekt nie posiada jeszcze stabilnego wydania.

Gotowe obrazy ISO będą publikowane dopiero wtedy, gdy projekt będzie miał działający i odpowiednio przetestowany build.

## 🛠️ Rozwój

MKXA OS jest rozwijany etapami. Najpierw powstaje działający system bazowy, a następnie dokładane są własne elementy projektu, takie jak wygląd, Fastfetch, instalator i konfiguracja.
